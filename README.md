## 📖 About

Somnia is a dream journal with an imagination. You submit a dream as text; behind the scenes:

1. 🧠 A **PydanticAI agent** running Llama 3.3 70B (via Groq) interprets and enriches the dream narrative
2. 🎨 An image-generation model (Together AI) turns that interpretation into artwork
3. ☁️ Dreams are stored in **Supabase**, keyed to your user ID

The repo includes sample outputs (`dream_image*.png`, `output.jpg`) generated by the pipeline.

## ✨ Features

- 🧠 **AI dream interpretation** — agentic enrichment of raw dream text
- 🎨 **Dream visualization** — text-to-image generation from the interpreted narrative
- 👤 **Per-user storage** — dreams persisted in Supabase by `user_id`
- ⚡ **Async FastAPI backend** — clean REST API for submitting and retrieving dreams

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Backend | FastAPI (async) |
| Agent | PydanticAI + Groq (`llama-3.3-70b-versatile`) |
| Image generation | Together AI |
| Database | Supabase |
| Frontend | Vite + React *(UI in progress)* |

## 🚀 Getting Started

### Backend

```sh
git clone https://github.com/tanishqsrivastavaa/Somnia.git
cd Somnia/backend
uv sync

export SUPABASE_URL="..."
export SUPABASE_KEY="..."
export GROQ_API_KEY="..."
export TOGETHER_API_KEY="..."

uv run uvicorn main:app --reload
```

### Frontend

```sh
cd frontend
npm install
npm run dev
```
